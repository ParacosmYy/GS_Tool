TRUST / DATA BOUNDARY

你的数据，留在中心服务边界内。

这是一份面向同学的简明说明。管理员应在分享链接前确认部署地址、保存期限和团队治理规则。

会记录什么

模型名称、输入/输出 token、调用时间、备注，以及你主动提交的工作方向、结果、效率评分和诊断日志。

谁能看到

普通账户只能看到自己的数据。管理员可以查看团队汇总、授权成员明细、脱敏日志和导出记录；相关操作写入审计表。

不会保存什么

provider API Key 不写入数据库、CSV 或应用日志。Android 的密码、access token 和 refresh token 不写入普通偏好设置。

数据在哪里

当前中心数据库保存在运行 Windows 服务的主机上。网页与 Android 通过 `/api/v1` 访问，不直接共享 SQLite 文件。

分享前请确认 正式公网访问必须使用 HTTPS、备份、访问日志脱敏、明确的数据保存期限和参与者知情同意。局域网预览只适用于可信网络。
