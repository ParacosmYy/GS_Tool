# UI 可访问性与视觉证据 · v114

## 变更主题

修复共享导航模块的滚动进度同步：Dashboard 图表、记录刷新和异常补录展开都可能改变文档高度，单靠 `scroll`/`resize` 无法保证进度线与真实页面比例同步。现在通过 `ResizeObserver` 观察 `document.body`，复用既有 `requestAnimationFrame` 调度重算；进度线改为固定宽度并使用 `scaleX`，避免异步布局期间反复改变自身宽度。

隔离实例：`127.0.0.1:5215`，运行目录为 `windows/.cache/ui-v3900-runtime-20260812-5215`。受保护服务 `5000/5011` 未触碰。

## 浏览器证据

- Dashboard 初始加载后，导航上下文完成初始化；进入 `scrollY=620` 后根变量正确更新，例如 `--scroll-progress=20.70%`。
- 展开“异常补录”后，文档高度从 `3895` 增加到 `4467`，进度从 `65.93%` 自动重算为 `55.19%`，无需额外滚动事件；伪元素进度线同步为 `867.635px`，`details.open=true`。
- 稳定滚动态采样：`scrollY=0/620/1400/2600` 对应 `scaleX=0.0000/0.2070/0.4674/0.8681`；进度线自身宽度固定为桌面顶栏宽度 `1320px`，不再读取为 `0px` 的过渡中间态。
- `320×720`、`390×844`、`768×900`、`1024×900`、`1440×900`：均无横向溢出；`1 个 h1 / 8 个 h2`；进度变量在首屏为 `0.00%`，滚动后更新；页面日志数量为 `0`。
- 应用页面截图确认顶部 AI TOKEN 透明品牌行、滚动进度线和深滚内容仍保持原有层级；浏览器运行时第三方 telemetry warning 不计入应用错误。

## 动效协议

- 信息：进度线表达当前页面阅读位置，并在异步内容高度变化后保持比例真实。
- 触发：滚动、窗口尺寸变化或 body 尺寸变化；统一经 `requestAnimationFrame` 合帧，过渡为 `transform .28s`，不触发布局。
- 降级：`prefers-reduced-motion` 继续由既有 CSS 关闭过渡；逻辑仍更新静态比例。
- 设备：ResizeObserver 仅在浏览器支持时启用；不支持时保留 scroll/resize 回退，触摸与键盘路径不被拦截。

## 角色复核

- UI：进度线仍是单一 signal 高亮，不增加面板或装饰层。
- 前端：变化限定在共享导航模块和共享品牌样式，新增的 `--scroll-progress-scale` 是内部 CSS 变量，不改变 API/DOM 契约。
- 后端：无后端、数据库、接口或密钥处理改动。
- 架构师：观察页面尺寸而非业务状态，保持 UI→导航模块边界，无轮询、无循环依赖；文件行数低于 1000 行。
