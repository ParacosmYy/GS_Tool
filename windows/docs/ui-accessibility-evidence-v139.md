# UI Accessibility Evidence v139

日期：2026-08-12

## 变更范围

本轮只修正 Dashboard 窄屏背景的视觉焦点。真实 390×844 截图显示，原有裁切将笔记本屏幕、人物和高亮设备推入 `TOKEN SIGNAL`、说明文案与 CTA 的阅读轨道，形成文字与背景高亮相互竞争的噪声。桌面布局和顶栏透明契约不变。

共享 `ui-polish.css` 在 620px 及以下将 `.story-backdrop` 与可选的 `.story-backdrop-image` 对齐到 30% 焦点。该规则同时覆盖 5000 旧启动链（只有 `style.css + ui-polish.css`）和 5011 完整启动链，并使用 `body` 特异度覆盖完整链后置的 68% 移动默认值；没有使用 `!important`。

## 可访问性与降级

- 本轮只改变装饰性背景裁切，不改变 DOM、交互脚本、键盘顺序、周期按钮语义、表单、图表或数据流。
- `prefers-reduced-motion` 与 `forced-colors` 规则未被移除；强制配色仍可隐藏装饰性场景层。
- 两个启动链共用同一焦点契约，避免旧缓存入口与完整入口出现不同视觉结果。
- 所有修改文件继续低于 1000 行：`ui-polish.css` 936 行，`scene-motion.css` 385 行，`style.css` 674 行。
