# UI-3 可访问性与视觉证据 v98

## 变更边界

- **问题**：指标栏直接叠在人物、代码和设备插画上；仅依靠文字阴影时，`INPUT TOKENS`、`OUTPUT TOKENS` 和 `ACTIVE MODELS` 的数值扫读成本较高。
- **实现**：`responsive-tuning.css` 为每个 `.signal-cell` 增加低 alpha 的局部渐变阅读层和极轻分隔线；移除会把移动端三个单元渲染成连续深色横带的 `backdrop-filter`，保持背景透景。
- **交互边界**：不改变透明 AI TOKEN 顶栏、DOM、导航、API、认证、表单值、数据流、Tab 顺序或指标布局。
- **文件边界**：变更集中在响应式表现层，`ui-polish.css` 保持 995 行；forced-colors 继续由系统色彩契约接管。

## 隔离浏览器观察

- 实例：`http://127.0.0.1:5194/dashboard`，隔离账号仅用于本地视觉观察。
- 390px 截图：指标单元保留人物与设备透景，不再形成连续黑色横带；单元计算样式为 `backdrop-filter = none`，顶栏同样为 `transparent / none / none`。
- 五档矩阵：`320×720`、`390×844`、`768×900`、`1024×768`、`1440×900` 均无横向溢出；指标单元在移动端保持自然纵向分隔，桌面端保持三列分隔。
- 深滚：`720px` 采样保持透明顶栏和可读指标，不新增 sticky 背景或遮罩。

## 可访问性与稳定性

- 五档回归中当前可见控件均具备名称：移动端 `39/39`；标题结构保留 1 个 `h1`、8 个 `h2`。
