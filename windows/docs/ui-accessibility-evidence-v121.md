# UI 可访问性与视觉证据 · v121

## 变更主题

收紧移动端登录/注册入口的垂直节奏。原先 `390×844` 下认证卡片约从 `y=511` 才开始，用户需要穿过完整介绍区后才能看到输入表单；本轮只在基础 `style.css` 的移动媒体查询中减少介绍区与卡片之间的空隙，保留标题、三条信任信息、表单字段、认证接口和场景图层。

用户服务：`127.0.0.1:5000`，验证期间未重启或修改运行数据。

## 浏览器证据

- `/login` 与 `/register` 在 `320×844`、`390×844`、`768×900`、`1024×900`、`1440×900` 均无横向溢出，`document.documentElement.scrollWidth - innerWidth = 0`。
- `390×844` 登录卡片从约 `y=511` 提前到 `y=479`；首个输入框从约 `y=725` 提前到 `y=694`，仍保留标题、说明和三条信任线。
- `1440×900` 桌面构图保持双栏比例，认证卡片宽度和背景场景没有改变；`768×900` 窄桌面卡片仍在内容宽度内。
- 登录与注册均保留 `1 个 h1 / 1 个 h2`，字段自动聚焦存在，密码字段与提交按钮的键盘 Tab 顺序正常。
- 键盘焦点落在提交按钮时，按钮具备可见 `outline` 和既有 signal shadow；应用页 console error/warn 数量为 `0`。

## 工程与无障碍协议

- 只增加移动媒体查询，不新增 DOM、依赖、事件监听器、网络请求或数据状态。
- `min-height: 700px` 仅用于常规手机高度；极矮视口继续使用原有布局，避免压缩造成内容遮挡。
- `prefers-reduced-motion`、`forced-colors`、原生表单 label 和既有焦点样式不变。
- `style.css` 共 550 行，未超过项目 1000 行约束。

## 角色复核

- UI：移动端更快进入主要任务，同时保留品牌故事和信任信息，减少首屏滚动负担。
- 前端：修改限定在共享认证展示媒体查询，不触碰模板语义、认证 JS、接口和 CSRF。
- 后端：无后端、数据库、认证、Key 生命周期或数据流改动。
- 架构师：变化归属 `02-auth` 的响应式表现边界，回滚为删除 v121 媒体查询；无新依赖和跨模块耦合。

## 未关闭门禁

真实设备、辅助偏好、Provider 联调、Android/EXE 构建、正式 HTTPS 与部署验收仍按项目总门禁执行，本证据不替代这些门禁。
