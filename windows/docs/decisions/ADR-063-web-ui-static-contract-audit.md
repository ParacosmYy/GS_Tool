# ADR-063：Web UI 静态契约发布门禁

## 状态

已接受（2026-08-10）。

## 背景

UI-3 的真实设备、合法会话和运行时错误路径不能由源码搜索替代，但模板层仍有一组可以在每次
交付时稳定检查的约束：装饰图片必须声明 alt、表单控件必须有可见 label 语义、数据表必须有
caption 与 scoped heading，页面必须保留跳过链接，动效必须提供 reduced-motion 和 forced-colors
降级。

## 决策

- `token_tracker audit` 增加 `web-ui-contracts` 只读检查，使用 Python 标准库解析模板，不执行
  Jinja、不创建用户/数据库、不访问浏览器或网络。
- 该检查只证明静态结构和降级钩子；真实 320/768/1024/1440 指标、焦点、会话、错误、导出、
  API 失败和图表渲染仍必须由 UI-3 运行时证据完成。
- 发现契约问题时返回 `fail`；外部浏览器/账号/设备工具缺失继续保持独立 `pending`，不降低静态
  门禁标准。

## 验证边界

- 已完成：模板控件、图片、表格、跳过链接和三种 CSS 可访问性降级的本地审计。
- 待完成：合法会话和真实设备的 UI-3 验收。

## 回滚

若审计实现阻塞紧急回滚，可暂时移除 `web-ui-contracts` 检查，但必须在同一变更中恢复并记录
缺失证据，不得将未执行的 UI-3 运行时验收标为通过。
