# ADR-055：登录场景背景 v7 视觉升级与跨端一致性

## 状态

已接受（2026-08-10）。

## 问题

v6 已经建立嵌入式 Rust/RL 工作台的品牌识别，但场景仍需要更明确的角色气质、设备层次和
工程学习氛围，才能支撑登录页、个人观测台和 Android 端的长期视觉记忆点。背景仍不能侵入
正文对比度、交互命中和窄屏信息层。

## 决策

- 使用 `embedded-rust-engineer-bg-v7.png` 作为 Web 当前默认场景，并将同一像素资产复制为
  Android 的 `embedded_rust_engineer_bg_v7.png`。右侧保持单个成年、御姐气质且非性化的二次元
  嵌入式工程师，手持银色 Pro 笔记本；工作台放置 Mac Studio 风格桌面计算机、示波器、开发板、
  服务器和抽象 Rust/RL telemetry。
- 画面左侧保留约 40% 的低细节暗色负空间，供认证卡片、仪表盘标题和数据正文使用；原始图片
  不承载可读文案、品牌 logo 或真实硬件状态，产品文字与连接状态必须由页面和业务数据渲染。
- v7 只替换静态资源引用，不改变 `.story-backdrop` 的遮罩、pointer follower、背景视差、
  `prefers-reduced-motion` 降级和 Android 低幅漂移策略；v6 及之前版本继续保留，支持回滚。
- 发布审计以 Web/Android 两份 v7 文件的 SHA-256 一致性和源文件 1000 行门禁作为静态准入条件。

## 验证边界

- 已完成：v7 图片生成、项目文件复制、Web/Android 引用切换、同 SHA-256 检查、图像目视检查。
- 已完成：新图片仍保持左侧负空间、右侧主体安全区和可读性遮罩约束。
- 待完成：具备合法认证会话后重新生成仪表盘、管理员和连接页的四档浏览器证据；Android
  工具链批准后完成编译、安装和设备视觉验收。

## 回滚

将 Web 引用恢复为 `embedded-rust-engineer-bg-v6.png`，Android 引用恢复为
`embedded_rust_engineer_bg_v6`，并同步恢复发布审计的 v6 文件名；不删除 v7 资产。
