# ADR-062：工程师场景的可见度构图

## 状态

已接受（2026-08-10）。

## 背景

v7 主图已经满足角色、Pro 笔记本、工作站和 Rust/RL 工程语义，但原全屏遮罩在普通显示器上
把右侧主体压得过暗，用户只能看到少量轮廓。视觉层需要强化品牌记忆，同时不能让正文、认证卡
和数据面板依赖插画像素承载可读性。

## 决策

- 桌面场景层保持左侧 0%—46% 的深色安全区，右侧 70%—100% 只使用低强度遮罩，让角色、
  笔记本、Mac Studio 风格工作站和示波器保持可辨识层次。
- 通过固定内容层、认证/数据面板不透明渐变和正文颜色 token 隔离信息与插画；插画始终是
  `aria-hidden` 的装饰层，不承载状态、文案或交互。
- 移动端、高对比度和 Windows forced-colors 继续使用更强遮罩或移除插画，优先保证阅读、
  焦点和系统可访问性。

## 验证边界

- 已完成：当前源码临时服务的 Chrome 1440px 登录页视觉观察，确认主图可见且表单文字保持清晰。
- 已完成：Python 编译、只读发布审计、source line cap 和 diff 检查。
- 待完成：合法会话下仪表盘/管理员页四档浏览器证据，以及真实移动设备视觉验收。

## 回滚

恢复 ADR-055 对应的 `.story-backdrop::before` 遮罩梯度和 `brightness(.98)`，不删除 v7 资产。
