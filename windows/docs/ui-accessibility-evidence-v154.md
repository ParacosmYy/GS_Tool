# UI Accessibility Evidence v154

日期：2026-08-12

## 变更范围

本轮只收敛短屏手机的 Dashboard 首屏编排。`320×720` 的原始构图同时承载
轨道、标题、说明、双 CTA、周期游标与装饰性 `Scroll to explore`，导致周期控件
被视口底部裁切。本轮新增 `mobile-hero-scan.css`，仅在 `max-width: 360px` 且
`max-height: 760px` 时：

- 将 `.hero-orbit` 从约 `250px` 收敛为 `185.59px`，保留视觉锚点但释放首屏垂直空间。
- 隐藏非交互的 `.scroll-cue`，不改变真实控件的 DOM 顺序、名称或焦点行为。
- 保持 Today / Week / Month / All time 周期按钮完整进入首屏；桌面和普通高度手机不命中该规则。

本轮不改变模板语义、认证、导航、接口、数据库、Provider、Key 或数据流。

## 工程与降级

- 新规则位于独立短屏 presentation module，由 `ui-polish.css` 统一导入；不新增依赖、脚本、监听器或接口。
- `forced-colors` 与 `prefers-reduced-motion` 不依赖本轮新增动画；系统色和既有动效降级继续生效。
- `!important` 仅用于短屏 orbit/cue 边界，以压过两个启动链共享的既有移动 fallback；作用域限定在短屏媒体查询内。
- 修改后的文本源码均低于 1000 行；本轮未创建或运行测试专用资产。

真实设备辅助偏好；这些发布项继续按项目发布清单保持 pending。
