# UI Accessibility Evidence v155

日期：2026-08-12

## 变更范围

本轮只调整认证页的阅读窗材质，解决登录卡片在场景图上仍像深色不透明面板的
视觉断层。`auth-signal.css` 保持认证字段、焦点、DOM 顺序和移动端卡片优先级不变，
仅收敛普通配色下的表面参数：

- 桌面认证卡片渐变 alpha 从 `.48/.60` 收敛为 `.36/.48`，blur 从 `10px` 收敛为 `8px`。
- 移动认证卡片渐变 alpha 从 `.46/.56` 收敛为 `.30/.42`，blur 从 `9px` 收敛为 `7px`。
- 输入框保留独立阅读底：桌面/移动分别使用 `.36/.38` alpha，保证文字与占位提示稳定可读。
- 阴影同步减弱，场景角色、设备和蓝色环境光重新参与卡片周边层次。

本轮不改变模板语义、认证接口、会话、导航、Dashboard、数据库、Provider、Key
或数据流。

## 工程与降级

- 变化限定在既有 `auth-signal.css` 认证 presentation boundary，无新依赖、脚本、监听器或接口。
- `prefers-reduced-motion` 仍关闭表面过渡；`forced-colors: active` 继续由系统色接管，不依赖半透明材质。
- 输入框保持更高 alpha 的局部阅读底，避免把“透景”误做成低对比度表单。
- 修改后的文本源码均低于 1000 行；本轮未创建或运行测试专用资产。

## 未覆盖发布门禁

本轮不涉及 Android、EXE 签名、真实 Provider、HTTPS/ACL、备份恢复、限流或
真实设备辅助偏好；这些发布项继续按项目发布清单保持 pending。
