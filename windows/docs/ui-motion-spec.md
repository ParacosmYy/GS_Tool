# UI 与动效规范

实现状态机见 [`motion-contract.md`](motion-contract.md)，颜色和间距真相见 [`design-tokens.md`](design-tokens.md)。
实现边界与模块职责见 [`ui-motion-architecture.md`](ui-motion-architecture.md)。本文件只保留视觉和交互验收规则。

## 视觉基线

- 近黑背景，正文使用高对比暖白；辅助文字至少保持可读的灰阶，不用低对比色制造“高级感”。
- 颜色按 Material 3 的 `background / surface / on-surface / on-surface-variant / outline / primary` 语义分配；同一语义不能在不同页面随意换色。
- 正文、label、placeholder 和图表刻度不使用接近背景的灰色；表单边框、键盘焦点和错误态必须在暗色背景中被看见。
- 一个页面只保留一个主强调色 `--signal`，用于当前状态、数据焦点和可操作反馈。
- 面板使用细线框和大留白；不使用四个同质化彩色统计卡片承载全部层级。
- `TOKEN / SIGNAL` 是产品自己的核心叙事；Moonshot 只作为视觉语言参考，不复制品牌标识或素材。
- `embedded-rust-engineer-bg-v7` 仅作为装饰层：右侧承载成年、御姐气质且非性化的二次元嵌入式 Rust/RL 工程师、银色 Pro 笔记本、桌面 Mac Studio 风格计算机与实验场景，左侧必须保留给标题和数据；遮罩、文字和交互层拥有更高视觉优先级。

## 动效层级

| 层级 | 动效 | 目的 | 降级 |
|---|---|---|---|
| 1 | 页面淡入、滚动 reveal | 建立进入节奏 | 直接显示 |
| 2 | 中心轨道、粒子、核心呼吸 | 表达 token signal | 静态环形视觉 |
| 3 | 标题 glitch、扫描线 | 对齐官网的数字/空间感 | 保持纯文字 |
| 4 | 鼠标 aura/ring、面板 sheen | 让用户感到页面响应 | 不显示跟随层 |
| 5 | 数字 count-up、状态过渡 | 连接数据变化和视觉变化 | 直接更新数值 |

## Easing 与节奏

- 进入和位移动画优先 `cubic-bezier(.16, 1, .3, 1)`，避免线性移动显得机械。
- 永久循环只允许使用轨道、呼吸、低频扫描；禁止大面积文字不停抖动。
- hover 不使用突兀的 `scale(1.1)`；面板最多上移 5px，按钮以颜色/边框/箭头位移反馈。
- 所有动画必须遵守 `prefers-reduced-motion: reduce`。

## 可读性与交互

- 页面主标题、正文、辅助说明分层明确；数据变化不能只靠颜色表示。
- 所有表单控件有可见 label，异步提交有成功/失败状态。
- 鼠标跟随层 `pointer-events: none`，不能拦截点击，也不能影响键盘焦点。
- Chart.js 只负责绘图，关键数字和记录表必须同时以可读文本存在。
- 自动采集是主入口；手动补录必须折叠并标明仅用于 provider 缺失 `usage` 的异常场景。
- 登录/注册页使用同一套轨道、扫描和高对比表单语言；入场层次为品牌/场景 → 表单卡片 → 字段反馈，避免认证页成为无动效的孤立页面。
