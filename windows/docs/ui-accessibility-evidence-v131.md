# UI 与可访问性证据 v131

## 变更主题

本轮处理 Dashboard 长页面的材质断层：图表空态已经是深蓝观测窗，但自动采集、协议说明、工作信号、活动历史和最近记录仍接近不透明黑面，移动端长表单尤其容易与固定场景高光混在一起。

- 旧 5000 入口通过 `legacy-observatory.css` 为长页面数据面补齐低 alpha 深蓝阅读窗。
- 自动采集卡使用略高于普通卡片的阅读底，工作信号、协议、活动历史和最近记录共享同一 surface family。
- 普通数据面使用 `blur(10px) saturate(1.04)`、边界 `rgba(230,235,245,.24)`；移动端仅提高背景 alpha 一档，不改变尺寸、字段或排版。
- `forced-colors`、`prefers-reduced-motion`、sticky 遮挡 mask、焦点恢复和现有展开态语义保持不变。

## 交互与可访问性

- 移动端周期按钮点击 Week 后，`aria-pressed` 为 `[false,true,false,false]`，active class 与状态同步。
- 手动补录 `<details>` 可由 summary 点击展开；展开态边界为 `rgba(217,255,120,.46)`，正文进入正常文档流。
- 页面仍为 `1 个 h1 / 8 个 h2`；本轮未改 DOM、字段 label、键盘顺序或 API。
- sticky 遮挡状态下卡片仍保持 `focus-within` 恢复逻辑，未将控件永久设为不可操作。

## 工程边界

- 修改仅涉及 `legacy-observatory.css`；没有新增依赖、模板、脚本、后端、认证、数据库、Provider Key 或数据流改动。
- 旧入口兼容规则仍独立于通用 `ui-polish.css`，完整样式链通过同一 import 继承，保持高内聚。
- 回滚点：移除 v131 新增长页面 surface block，即可回到 v130 的卡片材质。
