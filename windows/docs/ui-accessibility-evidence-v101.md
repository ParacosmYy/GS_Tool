# UI-3 可访问性与视觉证据 v101

## 变更边界

- **问题**：登录页认证卡片在真实场景上仍偏向黑色大块，背景插画无法参与层次，移动端尤其明显。
- **实现**：`responsive-tuning.css` 在普通配色下将 `.auth-card` 收敛为低 alpha 深蓝透景层，保留 `14px` blur、表单阅读密度、顶部高光和聚焦态边界；不改变认证结构或表单逻辑。
- **交互边界**：不改变 DOM、字段、认证请求、焦点顺序、Tab 路径、导航或数据流；forced-colors 继续由系统色彩契约接管。
- **文件边界**：变更只落在响应式表现层；`ui-polish.css` 保持 995 行。

## 隔离浏览器观察

- 实例：`http://127.0.0.1:5201/login`，隔离页面仅用于本地视觉观察。
- 真实矩阵：`320×720`、`390×844`、`768×900`、`1024×768`、`1440×900` 均确认卡片在视口内、无横向溢出；`.auth-card` 计算样式为 `backdrop-filter: blur(14px) saturate(1.08)`。
- 390px 截图：卡片从黑色实心感收敛为深蓝透景层，字段和主按钮保持稳定对比，背景角色与代码场景重新可见。
- 桌面截图：认证卡片与左侧 editorial intro 保持双栏层级，不改变宽度、边界或表单位置。
