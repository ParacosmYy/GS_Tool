- 任何源文件不超过 1000 行，且有统一文件头和公共接口注释。
- Python 编译、CLI help、启动/健康检查和真实浏览器证据必须记录。
- Android 工具链未安装时，只报告配置静态检查，不宣称 APK 构建成功。
- 不创建或运行默认单元测试、mock、fixture、harness 或测试专用资产。
- 最终交付必须列出已完成、未完成、风险和下一步，不用“看起来可以”替代证据。
