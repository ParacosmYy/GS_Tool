# M2a Review：TCP Client + UDP 单播

日期：2026-08-09  
范围：SerialForge 当前 checkout 的 TCP Client、UDP 单播、共用会话/终端/记录器、
Qt 配置和 Windows 打包。J-Link RTT、SEGGER、BLE 和 TCP Server 不在本轮。

## 角色评审结论

本轮按六角色合同完成产品、架构、UI、开发、验证和打包评审。冻结结果记录在
`docs/adr/0003-network-m2a-transport-boundaries.md`：M2a 只有单活动 TCP Client
和固定远端 UDP 单播；stream 与 datagram 端口、读取结果和 peer 元数据保持分离。

## 代码范围

- `domain/models.py`：TCP/UDP 配置、`PeerAddress`、stream result、datagram DTO 和
  payload 上限；
- `domain/ports.py`、`domain/events.py`、`domain/errors.py`：typed stream/datagram
  port、peer-aware 事件、EOF/非法 peer/超限错误；
- `infrastructure/tcp_transport.py`、`udp_transport.py`、`network_transport.py`、
  `transport_factory.py`：Python 标准库 socket 适配器和 typed routing；
- `application/sessions.py`：单 worker 有界队列同时消费 stream/datagram result，
  TCP EOF 不再与 timeout 混淆，UDP 丢弃保持可见且不写部分记录；
- `presentation/main_window.py`、`viewmodels.py`：UART/TCP Client/UDP 配置切换，
  复用同一终端、暂停预览、历史、快捷命令和原始 JSONL；
- `docs/`：ADR、路线图、架构、协议和本记录。

## 未运行与风险

- 未连接真实 USB-UART、真实 LAN peer、Windows 防火墙规则或硬件回环；
- UDP 当前 M2a 只实现 IPv4 单播，IPv6、广播、多客户端和协议序列号统计留给后续；
- 没有应用层序列号时不推断网络丢包/乱序；当前只观察本地非法来源、超限和发送错误；
- 未运行长时间高吞吐 soak、真实网络断电恢复和防火墙超时矩阵；
- J-Link 驱动尚未安装，RTT 明确留到最后，当前产物不含 RTT/SEGGER 依赖。
