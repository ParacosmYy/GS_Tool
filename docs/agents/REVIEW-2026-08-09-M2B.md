## 代码与边界

- `domain/models.py`：`TcpServerTransportConfig`、IPv4/CIDR 规范化、`ServerReadResult`、reject/client 状态；
- `domain/ports.py`：独立 `TcpServerTransportPort` 与 server factory port；
- `infrastructure/tcp_server_transport.py`：监听 socket、单 client 槽位、allowlist、busy/unauthorized、socketpair 唤醒；
- `application/tcp_server_sessions.py`：listener 生命周期、client 事件、固定当前 client 的有界发送队列、原始记录；
- `application/session_router.py` 与 `composition.py`：M2a 和 server manager 路由隔离；
- `presentation/main_window.py` 与 `viewmodels.py`：TCP Server 配置、双层状态、无 client 禁止发送；
- 文档：ADR 0004、路线、架构和传输协议边界同步。

## 运行证据

静态与依赖门：

- `uv lock --check`：通过；
- `./scripts/check.ps1`：通过；
- `uv run --locked --extra dev ruff format --check src`：27 个文件已格式化；
- `uv run --locked --extra dev ruff check src`：通过；
- `python -m compileall -q src`：通过。

手工 localhost socket 回环：

- listener `OPEN` 后首个 client 接入，RX `M2B-CLIENT1`，TX `M2B-REPLY`；
- 第二个 loopback client 立即关闭，产生 `tcp_server_busy`，首个 client 不受影响；
- 首个 client EOF 产生 `DISCONNECTED`，listener 保持运行，新 client 可以再次接入；
- `manager.shutdown(timeout=2)` 后最终状态为 `closed`，worker 及时退出；
- 配置拒绝 hostname、IPv6、未确认非回环、空 LAN allowlist；合法 `0.0.0.0 + LAN confirmation + CIDR` 可构造。

原始 JSONL：

- 实际 client RX/TX 各一条，共 2 条；方向为 `rx`/`tx`；每条包含 `peer.host=127.0.0.1` 和来源端口。

Qt 与组合根：

- `QT_QPA_PLATFORM=offscreen` 创建窗口并切换 TCP Server；默认配置为 `127.0.0.1:9000`；首个 client 到来前 `can_send=False`；
- `create_application()` 通过 router 打开/关闭 TCP Server，最终 snapshot 为 `closed`。
