# 08 - 图标与视觉资产标准（重构版）

> 适用范围：PyQt 界面中的工具栏、按钮图标、状态图标与视觉资源。

---

## 一、视觉资产原则

- 优先使用 PyQt 可稳定加载的项目既有 icon 资产。
- 新图标必须统一风格（粗细、圆角、边界、基线对齐）并有来源记录。
- 禁止在代码散落硬编码 SVG 路径；统一走资源索引或等效管理。

## 二、命名与加载

- 文件名语义化：`module_action_state.svg`
- 禁止匿名序号命名（如 `icon1.svg`）
- 统一通过资源路径引用，避免运行时外部路径依赖。
- 图标变更需同步更新主题 token 与 UI 样式文档。

## 三、状态与主题

- 不同状态（normal/hover/disabled/active）由 QSS+状态类管理，不用手写不同 SVG 颜色集。
- 禁止重复加载同一资源导致的无意义性能损耗。
- 同一语义图标在不同功能区域必须共用，禁止多个等效副本。

### 3.1 图标量化验收

- 图标覆盖率：关键操作按钮必须 100% 有图标。
- 主题一致性：至少覆盖 normal/hover/disabled 三种状态。
- 首次启动图标加载不明显影响启动，不能明显增加启动耗时。

## 四、验收

> 完整门禁清单（5 视角 + 6 门禁）见 [09-closed-loop.md](09-closed-loop.md)。图标变更必跑项：

- 新增图标有：
  - 用途说明
  - 引用位置
  - 主题状态覆盖计划
- 资产体积与加载不导致启动阻塞（首次打开速度不可明显劣化）。
- 新增或修改图标后，须执行 `uv run test-embeddebug-py`、`uv run start-embeddebug --smoke` 与 `cmd /c EmbedDebug.bat --smoke`。

### 4.1 与评分的绑定

- 新图标未通过验证：本次提交 +0。
- 主题状态不完整：本次提交 +0。
- 覆盖完整并有文档映射后，仍需满足全门禁绿与 diff 修改行数≥1000，才可进入下一闭环 +1。
