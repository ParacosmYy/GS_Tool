## Support boundary

The last measured evidence supports only the recorded source/offscreen and
packaged EXE + Qt offscreen workloads for their historical artifacts on the
current Windows machine. It does not
approve a large-file support range, native-memory ceiling, clean-machine
guarantee, permission/disk-pressure guarantee, hard-power durability claim, or
cross-machine support claim.

- Product: approve the distribution channel and file-association policy.
- QA: execute the authorized clean Windows x64 and support-handoff matrix.
- Support owner: Project Manager (QuillForge).

  release manifest as the local offline intake route.
- Support packet: [`docs/support/HANDOFF.md`](support/HANDOFF.md), prepared
  locally with candidate identity, ownership, triage, and explicit acceptance

`no-go` after the open gates have authoritative evidence.
