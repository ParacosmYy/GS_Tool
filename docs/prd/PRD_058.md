# PRD-058: P2 Bug修复+终端UTF-8安全显示+连接健康UI反馈+重连Toast通知

## 背景
迭代#58。聚焦于#42审计中遗留的P2 Bug修复和#57新增信号的UI集成。
关键目标: 终端文本模式下二进制数据不再显示乱码方块，连接健康状态可视化，重连进度Toast通知。

## 需求列表
| ID | 需求描述 | 优先级 | 涉及模块 |
|----|---------|--------|---------|
| R1 | Terminal clear()同步model数据 | P2 | terminal/TerminalWidget |
| R2 | ToastWidget字体fallback链(跨平台) | P2 | core/ToastWidget |
| R3 | Terminal文本模式非UTF-8字节→\xNN显示 | P2 | terminal/TerminalWidget |
| R4 | connectionHealth信号→DataStatistics UI | P1 | serial/DataStatistics |
| R5 | reconnectProgress信号→Toast通知 | P1 | core/MainWindowSignalConnect |

## 接口设计

### DataStatistics新增
```cpp
/** @brief 更新连接健康状态 @param alive 是否存活 @param lastDataAgeMs 距上次数据毫秒数 */
void updateConnectionHealth(bool alive, qint64 lastDataAgeMs);
```

### TerminalWidget safeFromUtf8
```cpp
// 匿名命名空间静态函数, Text模式替代QString::fromUtf8()
static QString safeFromUtf8(const QByteArray& data);
```

## 依赖的公共组件
- ToastWidget (showInformation静态方法)
- DataStatistics (updateConnectionHealth)
- ConnectionController (connectionHealth/reconnectProgress信号)

## 验收标准
1. 终端Text模式下0x80-0xFF字节显示为\x80而非方块
2. ToastWidget在无Segoe UI Emoji的系统上仍能显示图标
3. 连接空闲>10s时DataStatistics显示"空闲 Xs"
4. 重连尝试时右下角Toast通知
5. 编译零错误, 文件行数合规
