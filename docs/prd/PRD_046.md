### 修复规则

对每个文件应用以下顺序:

```
1. 头文件卫士 (#ifndef / #define)        -- 仅.h文件
2. Doxygen文件注释 (/** @file ... */)     -- 可选
3. Qt头文件 (#include <Q...>)            -- 第一组
4. STL头文件 (#include <algorithm>等)     -- 第二组
5. 项目头文件 (#include "core/...")       -- 第三组，最后
```

组与组之间用空行分隔。同组内按字母序排列。

## 第二部分: P1 Bug修复

### BUG-045-01 [P1]: seekToBookmark时间戳坐标系不一致

- **位置**: `src/utils/DataLogger.h/cpp`
- **描述**: `addBookmark()` 使用 `QDateTime::currentDateTime().toMSecsSinceEpoch()` 记录Unix纪元时间戳，而 `.edl` 录制文件中的时间戳是距录制开始的偏移量（0起始毫秒数）。`seekToTimestamp()` 期望的是录制文件内部的相对时间偏移。坐标系不一致导致书签跳转功能完全失效。
- **修复方案**: 在录制模式下，`addBookmark()` 应记录 `m_recordTimer.elapsed() - m_pauseOffset` 作为书签时间戳（与录制文件中的时间戳坐标系一致）。在非录制模式下保留Unix纪元时间戳。
- **涉及方法**: `DataLogger::addBookmark()` 中计算时间戳的逻辑

### BUG-045-02 [P1]: 书签录制停止后不持久化

- **位置**: `src/utils/DataLogger.h/cpp`
- **描述**: `m_bookmarks` 仅保存在内存中，录制停止后书签集合丢失。`DataBookmark` 已实现 `toJson()/fromJson()` 序列化方法但未被使用。
- **修复方案**:
  1. `stopRecording()` 中将书签序列化为JSON追加到 `.edl` 文件尾部，写入书签段标记（如 `[BOOKMARKS]` + JSON行）
  2. `startPlayback()` 中检测并解析 `.edl` 文件尾部的书签段，反序列化恢复书签列表
  3. 向后兼容: 如果 `.edl` 文件无书签段，不影响正常回放

### BUG-045-03 [P1]: OtaWidget完成动画使用QPropertyAnimation("value")作为定时器

- **位置**: `src/ota/OtaWidget.cpp` 第407~417行
- **描述**: 完成变色动画使用 `QPropertyAnimation(m_progressBar, "value")` 且 startValue=endValue=100，将动画框架当作400ms定时器使用。这是hack写法，可能导致不必要的重绘。
- **修复方案**: 替换为 `QTimer::singleShot(400, this, [this]() { ... })`，逻辑等价但语义清晰。在lambda中设置progressBar的成功色。
