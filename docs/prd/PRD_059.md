# PRD-059: 新特性评估+架构清理+连接增强

## 背景
迭代#59(20×3新特性触发)。评估新特性候选并准备高级波形引擎提案。
同时进行架构清理: BackgroundSettingsPopup重构(89行变更)、ChannelConfig JSON验证增强、
TCP/UDP连接name()国际化、XModemTransfer错误处理增强、MainWindow面板切换优化。

## 新特性评估结果

- 目标: FFT频谱分析、多Y轴、游标测量、缩放平移
- 架构: 扩展ChartWidget + 新增FftEngine + CursorOverlay + MultiAxisScale
- 分阶段: 4个迭代(iteration #61-#64), 预估1600行新增代码
- 详见: FEATURE_WaveformEngine.md

### 暂缓: 数据录制回放增强
- 依赖高级波形引擎完成后才有意义(需要多流时间对齐)

### 暂缓: 虚拟串口回环
- Windows平台需要第三方驱动(com0com), 跨平台实现复杂
