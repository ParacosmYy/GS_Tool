# PRD-057: 串口深度+连接健康监控+JSON导出+OTA文件限制扩展

## 背景
迭代#57(19×3新特性触发点)。基于#51审计和explore探查结果，聚焦于:
1. 连接稳定性: 自动重连指数退避(替代固定间隔)
2. 数据导出增强: 新增JSON格式导出
3. 连接健康监控: 5s心跳检测+stale连接预警信号
4. OTA文件限制: kMaxFileSize 1MB→16MB(支持STM32H7等大Flash)
5. 端口信息增强: 系统路径+可用波特率提示+扩展波特率预设

## 需求列表
| ID | 需求描述 | 优先级 | 涉及模块 |
|----|---------|--------|---------|
| R1 | 自动重连指数退避: interval × 2^min(attempt,4), 上限30s | P1 | core/ConnectionController |
| R2 | 重连进度信号: reconnectProgress(attempt, maxRetries, nextMs) | P1 | core/ConnectionController |
| R3 | 连接健康信号: connectionHealth(alive, lastDataAgeMs) 每5s | P1 | core/ConnectionController |
| R4 | JSON导出格式: exportJson + exportStreamedJson | P1 | utils/DataExporter |
| R5 | OTA文件限制扩展: 1MB→16MB | P2 | ota/protocols/BaseTransfer |
| R6 | 端口tooltip增强: 系统路径+波特率提示 | P2 | serial/SerialConfigPanel |
| R7 | 波特率预设扩展: 230400/460800/921600/1000000 | P2 | serial/SerialConfigPanel |

## 接口设计

### ConnectionController 新增
```cpp
signals:
    /** @brief 重连进度通知 @param attempt 当前尝试次数 @param maxRetries 最大重试次数 @param nextIntervalMs 下次间隔(ms) */
    void reconnectProgress(int attempt, int maxRetries, int nextIntervalMs);
    /** @brief 连接健康状态 @param alive 连接是否存活 @param lastDataAgeMs 距上次数据的毫秒数 */
    void connectionHealth(bool alive, qint64 lastDataAgeMs);

private:
    int m_reconnectAttemptCount = 0;  ///< 重连尝试计数(成功后归零)
    QElapsedTimer m_lastDataTimer;    ///< 距上次收到数据的时间
    QTimer* m_healthTimer = nullptr;  ///< 连接健康检测定时器(5s)
```

## 验收标准
1. 自动重连: 第1次间隔3s, 第2次6s, 第3次12s, 第4次24s, 第5次30s(封顶)
2. JSON导出: 文件可被jq或Python json.load正确解析
3. 连接健康: 已连接状态下每5s发射一次信号
4. OTA文件限制: 支持传输最大16MB固件
5. 编译零错误, 所有.cpp ≤500行, 所有.h ≤200行
6. 所有新方法有中文Doxygen注释
7. 所有用户可见字符串使用tr()
