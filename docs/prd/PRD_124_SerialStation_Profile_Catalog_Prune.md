# PRD-124 Serial Station 失效档案自动清理

## 背景

Serial Station 已支持保存、加载、最近档案、清空最近档案和上次档案快捷启动。工位现场常见情况是档案位于临时目录、U 盘或共享路径，文件被删除或迁移后，最近档案列表会保留不可用路径，影响启动回到工作状态的确定性。

## 目标

1. 最近档案索引支持清理已不存在的 `.edserialprofile` 路径。
2. 清理后自动把上次档案回退到第一个仍存在的最近档案。
3. 工作台提供“清理失效”入口，并通过系统日志反馈清理数量。
4. `--last-profile` 启动时若上次档案已不存在，自动清理并回退到下一个可用档案。

## 非目标

1. 不扫描磁盘寻找移动后的档案。
2. 不删除、移动或重写真实 `.edserialprofile` 文件。
3. 不改变最近档案持久化格式。
4. 不自动连接真实串口，本轮仍为 D1 自动化验证。

## 用户故事

作为嵌入式调试工程师，我希望最近档案列表能快速移除失效路径，并在上次档案丢失时自动尝试下一个可用配置，从而减少工位启动后的手动修复。

## 验收标准

1. 服务层能清理不存在的最近档案路径，并返回清理数量。
2. 清理后仍保持已有档案的原有顺序。
3. 清理后上次档案指向第一个仍存在的最近档案；若没有可用档案则清空上次档案。
4. UI 存在 `serialProfilePruneMissingButton`，点击后刷新最近档案控件并写入系统日志。
5. 启动加载上次档案时，若当前上次档案不存在但存在其他最近档案，则自动回退加载。

## 三轴目标

```text
Engineering: E5，服务持久化和工作台启动回退均有 QTest
User path:   U4，用户可一键清理失效最近档案
Device:      D1，不触碰真实串口连接验证
```
