## 接口设计

### R1: 错误计数器修正

```cpp
// SerialConnection.cpp onError() — 修正映射
// Qt QSerialPort不区分FramingError/ParityError
// 正确做法: ResourceError → unknownErrors, TimeoutError → unknownErrors
// 保留原有错误翻译字符串不变
```

### R3: Break信号按钮

```cpp
// SerialConfigPanel.h 新增
QPushButton* m_breakBtn;              ///< Break信号按钮
void breakRequested(int duration);    ///< Break信号请求

// SerialConfigPanel.cpp — 在DTR/RTS按钮旁添加
m_breakBtn = new QPushButton(tr("BRK"));
m_breakBtn->setObjectName("breakBtn");
connect(m_breakBtn, &QPushButton::clicked, this, [this]() {
    emit breakRequested(100);  // 默认100ms
});

// ConnectionController.cpp — 连接信号
connect(m_serialConfig, &SerialConfigPanel::breakRequested,
        this, [this](int duration) {
    if (auto* conn = qobject_cast<SerialConnection*>(m_currentConn)) {
        conn->sendBreak(duration);
    }
});
```

### R4: 自动重连UI

```cpp
// SerialConfigPanel.h 新增
QCheckBox* m_autoReconnectCheck;      ///< 自动重连开关
QSpinBox* m_reconnectIntervalSpin;    ///< 重连间隔(ms)
void autoReconnectToggled(bool enabled, int intervalMs);

// MainWindowSignalConnect.cpp — 连接信号
connect(m_panelManager->serialConfig(), &SerialConfigPanel::autoReconnectToggled,
        m_connectionController, [this](bool enabled, int intervalMs) {
    m_connectionController->enableAutoReconnect(enabled, intervalMs);
});
```
