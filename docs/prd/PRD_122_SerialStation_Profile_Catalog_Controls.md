# PRD-122 Serial Station 最近档案目录管理

## 背景

PRD-121 已让 Serial Station 记录最近使用的 `.edserialprofile`，用户可以通过下拉列表或“重载上次”快速恢复工位配置。随着工位、产线和临时调试档案增多，最近档案列表也需要基本维护能力，否则无效路径和临时档案会长期留在入口里。

## 目标

1. 用户可以在工作台内清空最近档案列表。
2. 服务层提供可测试的档案路径查询与移除能力，支撑后续更细粒度的目录管理。
3. 清空操作只影响最近档案索引，不删除 `.edserialprofile` 文件。
4. 最近档案 UI 状态与持久化状态一致。

## 非目标

1. 不新增档案文件删除功能。
2. 不新增自动连接真实串口。
3. 不改变 `.edserialprofile` 文件格式。
4. 不提升设备验证等级，仍为 D1 自动化测试。

## 用户故事

作为嵌入式调试工程师，我希望在工作台中清理最近档案列表，避免临时测试档案污染常用工位入口。

## 验收标准

1. 新窗口打开时能够反映已持久化的最近档案列表。
2. 点击“清空最近”后，下拉列表为空，“重载上次”和“清空最近”禁用。
3. 清空后新窗口不再显示旧的最近档案。
4. 清空后仍可重新加载或保存档案，并重新写入最近档案列表。
5. 服务层支持查询路径是否存在、移除单一路径、清空所有路径。

## 三轴目标

```text
Engineering: E5，服务层和 UI 闭环均有 QTest
User path:   U4，工作台内可维护最近档案入口
Device:      D1，不触碰真实串口验证
```
