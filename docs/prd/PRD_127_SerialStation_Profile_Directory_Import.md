# PRD-127 Serial Station 默认档案目录导入

## 背景

Serial Station 已支持保存/加载 `.edserialprofile`、最近档案、上次档案快捷启动、默认档案目录启动和默认目录持久化。当前缺口是：当企业工位已经有一批档案放在默认目录中时，用户仍需要逐个“加载档案”才能把它们加入最近列表。

企业级上位机应支持按工位目录快速整理配置，让产线调试人员可以一次把目录内档案纳入最近列表，再通过下拉框快速切换。

## 目标

1. 在 `SerialProfileCatalogService` 增加目录扫描能力，发现默认目录下的 `.edserialprofile` 与 `.json` 档案路径。
2. 增加批量导入能力，将扫描到的档案路径纳入最近档案索引。
3. `SerialStationWindow` 增加“导入目录”入口，扫描当前默认档案目录并刷新最近档案列表。
4. 导入动作不自动应用档案，不改变当前 UART/协议/命令状态。
5. 空目录、无效目录或无档案目录需要有明确系统日志反馈。
6. 导入动作不得删除真实文件，不改变默认档案目录。

## 非目标

1. 不递归扫描子目录。
2. 不自动连接串口。
3. 不自动选择或加载某个导入档案。
4. 不做档案内容校验；本轮只管理路径索引，内容读取仍由 `SerialProfileService` 在加载时校验。
5. 不提升真实串口设备验证等级，本轮仍为 D1 自动化测试。

## 用户故事

作为产线调试工程师，我希望把 `profiles/line-a/` 目录内的多个工位档案一次导入最近列表，这样后续可以直接从 Serial Station 顶部下拉框切换不同设备配置，而不是逐个浏览文件。

## 验收标准

1. 服务层能扫描目录内 `.edserialprofile` 与 `.json` 文件，并按文件名稳定排序。
2. 服务层对空目录、缺失目录、空路径返回空列表。
3. 服务层批量导入会去重、标准化路径，并复用最近档案容量上限。
4. 窗口暴露 `importProfilesFromDefaultDirectory()`，返回导入数量。
5. 顶部工具栏存在 `serialProfileImportDirectoryButton`。
6. 点击“导入目录”后，最近档案下拉框刷新，重载/清空/清理按钮状态同步。
7. 无档案时系统日志显示“未发现可导入配置档案”。
8. 有档案时系统日志显示导入数量。
9. 导入动作不改变当前工作台已应用的 UART/协议/命令状态。
10. README 中文企业级说明同步目录导入能力。
