# PRD-047: 串口功能全死角覆盖 + UI美化一致性 + 文件体积红线管控

## 背景

用户明确提出两个最高优先级诉求:
1. "百分之百保证串口可以无死角的使用跟配置" -- 串口是嵌入式调试工具的生命线，任何配置缺失或边缘场景失效都会直接阻断用户工作流
2. "最重要的还是ui要美观美化" -- 工具的专业感直接影响用户信任度和使用意愿

经代码审查发现以下三类问题:

**串口功能缺口** (对照 SerialConnection.cpp / SerialConfigPanel.cpp / ConnectionController.cpp):
- DTR/RTS 信号仅有 CheckBox，缺少运行时动态切换按钮（连接后切换不够直观）
- 自定义波特率通过可编辑 ComboBox 已支持，但缺少输入校验反馈（非法值静默失败）
- PortWatcher 仅有2秒轮询，连接中设备拔出后的自动断开和恢复流程缺少 UI 反馈层
- TCP/UDP 连接错误信息未翻译为中文，直接暴露英文 errorString
- 流控配置已存在但缺少说明文字帮助用户理解不同模式的适用场景
- 无连接超时配置 UI 入口（ConnectionController 硬编码 5000ms）

**UI 一致性缺口** (对照 dark_terminal.qss / modern_dark.qss / light.qss):
- 三个主题文件约1300行，结构基本一致，但存在部分细微差异需要校验
- connectBtn 的 state="error" 状态缺少 QSS 定义（dark_terminal.qss 中无此规则）
- 部分控件（如 recording 相关按钮、timedSender 相关控件）可能缺少跨主题一致性
- SerialConfigPanel 内部间距和分组布局有进一步优化的空间

**文件体积红线**:
- YModemTransfer.cpp 当前 499 行，距离 500 行上限仅剩 1 行缓冲，极其危险
- 需要预防性拆分或精简，避免后续任何改动直接越线

当前评分: 46/1000

### 接口设计

**R1 - DTR/RTS 按钮增强**:
```
// SerialConfigPanel.cpp - 连接状态下 DTR/RTS 切换为 ToggleButton 风格
// 通过 QSS property "signalState" 控制 ON/OFF 视觉:
// QCheckBox#dtrCheck[signalState="on"]  -> accent 色 + "DTR: ON"
// QCheckBox#dtrCheck[signalState="off"] -> 默认色 + "DTR: OFF"
// 无需新增类，在 setConnected() 中动态切换 property 即可
```

// SerialConfigPanel 内新增方法:

        this, &SerialConfigPanel::validateBaudRate);
```

```
