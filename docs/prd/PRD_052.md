## 接口设计

### IConnection.h 新增
```cpp
/** @brief 信号线状态结构体 */
struct PinoutSignals {
    bool cts = false;  ///< Clear To Send
    bool dsr = false;  ///< Data Set Ready
    bool dcd = false;  ///< Data Carrier Detect
    bool ri = false;   ///< Ring Indicator
    bool dtr = false;  ///< Data Terminal Ready (output)
    bool rts = false;  ///< Request To Send (output)
};

virtual PinoutSignals pinoutSignals() const;
```

### SerialConnection.h 新增
```cpp
PinoutSignals pinoutSignals() const override; // 使用QSerialPort::pinoutSignals()
```

### ConnectionController 新增信号
```cpp
void pinoutSignalsChanged(const PinoutSignals& signals);
```
