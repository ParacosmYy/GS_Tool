# UI-1.26：终端空态与响应式工具栏

日期：2026-08-10  
范围：presentation-only；终端空态、实时观测带、发送带、主题和动效生命周期  
父代理：Codex；共享 checkout 唯一写入者  
结果：`static=pass`；`offscreen=pass`；`package=pass`；`release=ineligible`

## 目标

解决终端区域的大块空白和实时观测/发送栏在窄窗口的拥挤问题，同时保持已有 transport、ViewModel、发送 gate、
记录、回放和协议语义不变。空态使用原创无 IP 的星轨几何，不引入图片、字体、GIF、QRC/QSS 文件或新依赖。

## 实现

- `src/serialforge/presentation/terminal_surface.py`
  - 新增 `TerminalEmptyState` 与 `TerminalOrbitGlyph`。
  - 只消费父层投影的 idle/waiting/transition/paused/history 和共享 motion frame。
  - 不持有业务状态、transport/application 引用、独立 timer 或用户操作。
- `presentation/controllers/bootstrap.py`
  - 新增 `terminalSurface` canvas，让 QPlainTextEdit 和空态层共享主题背景。
- `presentation/controllers/terminal_runtime.py`
  - 从既有 preview buffer、SessionState、history flags、preview paused 推导上下文。
  - RX 数据隐藏空态，清空/历史/状态/数据活动变化重新投影。
- `presentation/controllers/terminal.py`
  - 实时观测带、发送带由单行 HBox 改为两行 QGrid；保留 widget 名称、signal、Tab/快捷键顺序。
  - pause signal 使用无参 lambda adapter 调用既有 `_update_data_activity()`；暂停/记录标签采用 `Ignored + min/max`。
- `presentation/controllers/lifecycle.py`
  - close/hide/minimize 停止空态 glyph；minimize restore 显式解除 shared MotionController suspended。
- `theme_stylesheet_controls.py`、`theme_variant_controls.py`
  - 为 terminal surface/card/state/label 增加三主题 semantic selector；不使用白色回退。
