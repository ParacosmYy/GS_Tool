## 交付内容

- `main_window.py` 记录最近非错误状态；清除错误后恢复它，不再回显 ViewModel 中已清除前留下的错误状态。
- 发送按钮区分“可发送会话”和“有效 payload”：空文本、全空白 Hex 禁用；非法 Hex 保持可提交以显示格式错误；提交路径拒绝零长度 payload。TCP Server 无目标 client 时，单条和批量执行均禁用并给出明确提示。
- 回放开始/暂停/继续/停止、原始记录按钮补稳定 AccessibleName/Description；Component/Dataset 空态和 raw-only 不适用原因同时进入可见 placeholder 与辅助描述。
- 派生控件不适用时禁用并移出焦点链；恢复时保留并统一恢复协议帧快照、Component rows、Dataset samples 和曲线，避免部分缓存恢复。
- Dataset 预览仅在原本已位于底部时跟随最新 sample；用户阅读历史位置时不跳动。曲线最小宽度 260 px，关闭后的 curve empty message 更新被忽略。
- 接收、预览、记录、回放、暂停字节、状态、错误、send-ready、server-peer、session-state 与装饰帧的关闭路径加入早退保护；不改变 Raw 接收/记录/解析/回放语义。
