## 本轮已完成

### 状态与输入反馈

- UART 端点摘要随网络字段、BLE 设备和手动端口编辑实时更新。
- 已选 UART Endpoint 使用真实 `address` 连接；手动输入新端口不会沿用旧 Endpoint identity；未知手动端口不再被热插拔 identity 检查误报为“设备未发现”。
- TCP Server 连接按钮加入 IPv4、端口、LAN 确认、IPv4/CIDR allowlist 和归一化条目数量的前置提示；domain 仍保留最终校验。
- UART 刷新和 BLE 扫描显示“刷新中/扫描中”并禁用重复入口；ViewModel 发出明确 busy 状态信号，成功、失败和关闭路径均收敛。
- 协议应用/重置在存在派生状态或未应用草稿时先显示确认，明确说明会清空 Protocol/Component/Dataset 派生缓存而不影响 Raw/记录/历史文件。
- 初始 `ErrorInfo` 会在 MainWindow 水合；错误栏补充稳定的辅助名称和描述，保留状态栏与 tooltip 详情。

### 预览与动态效果

- 终端、协议帧和 Dataset 预览使用一个 80ms latest-wins single-shot presentation scheduler，减少高吞吐下反复整段 `setPlainText`。
- 隐藏、最小化、关闭阶段只保留有界最新状态；窗口恢复或协议页可见时再刷新。
- Dataset 曲线的派生来源 gate 同步到控件启用态和焦点策略；来源不适用时静态画布显示“当前来源不适用”，不抢键盘焦点。
- 现有 `MotionController` 仍是唯一装饰性动效时钟；本轮没有增加图片、GIF、粒子、字体、QSS/QRC 或新的第三方依赖。

### 输入与可访问性

- 快捷命令加入批量编辑器前校验最终 wire payload（含可选 CRLF）不超过单步上限；Hex 手动编辑超限时提前显示错误。
- Component table 和 Batch editor table 的所有单元格补充 `AccessibleTextRole`；摘要仍保持有界，完整内容保留在辅助文本/tooltip。
- Tab 页启用滚动按钮以降低高 DPI/窄窗下的标签挤压风险；已有显式 Tab 顺序和方向无关暗色主题保持不变。

## 设计、简化与剩余风险

- `preview_render_timer` 只合并文档重绘，不改变接收、记录、回放、Raw buffer 或业务状态；Component table、Dataset curve 仍各自保留原有生命周期边界。
- 端点 identity 只有在当前可见文本与所选/枚举 Endpoint 对应时才传递；未知手动 UART 地址不伪造 serial/location identity，并跳过无法可靠判断的热插拔身份检查。
- TCP Server 的 UI readiness 是提前反馈，不取代 `TcpServerTransportConfig` 的域校验。
- BLE 关闭时会设置 scan cancellation flag、清零 presentation busy 并抑制迟到 UI 回调；但 `BleakScanner.discover(timeout=...)` 的阻塞取消需要 infrastructure/application operation token，不能由 presentation-only 补齐。
- Replay EOF/EventBus control event 丢失、BLE service epoch/operation id/worker close race 未在本轮修改。
- 本轮为 Python desktop presentation 变更，embedded C/C++ applicability=`N/A`；不据此声称 MISRA、ISO、WCAG、认证或硬件合规。
