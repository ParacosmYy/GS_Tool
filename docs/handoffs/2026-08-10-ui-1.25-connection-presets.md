# UI-1.25 连接快速配置交接

日期：2026-08-10  
范围：连接带快速配置、内置 preset DTO、响应式布局和主题状态  
写入者：父代理 Codex；共享 checkout 未创建/操作 worktree

## 交付

- `presentation/connection_presets.py` 提供 schema v1 immutable `ConnectionPresetCatalog`、唯一 key、数量上限和
  typed values 范围校验。
- 内置 UART 115200 8N1、UART 9600 8E1、TCP Client、TCP Server、UDP、RTT Terminal、BLE GATT 扫描七项 preset。
- `presentation/controllers/connection_presets.py` 只把 preset 填入现有表单，不自动连接，不保存密钥、设备句柄或 BLE 身份；
  TCP Server loopback preset 会清除旧 LAN 确认与 allowlist。
- `connectionControlBand` 改为两行 `QGridLayout`，`connectionPresetCombo` 使用 bounded size hint，加入主题化 info/focus 状态和键盘 Tab 顺序。
- builder 通过 `ConnectionPresetApplyCallback` 调用 typed MainWindow wrapper；应用时阻断 transport signal 并只刷新一次。
- TCP Server 在传输切换、监听 host 或监听 port 变化时统一失效旧 LAN 授权；runtime 继续只消费规范化控件值，
  不直接反向依赖 presentation DTO。
- ARCH-7b 的 QSettings 用户自定义 catalog 未在本切片中提前实现，保持为后续独立 port/adapter。
