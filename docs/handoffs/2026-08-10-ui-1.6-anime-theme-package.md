## 用户目标与边界

用户明确希望 SerialForge 不再只是普通深色调试台，而是具有二次元主题感、组件层次和 UI 过渡动画的串口工具，并要求仓库根目录能直接看到打包出的 EXE。

本轮采用原创无 IP 的“星轨霓虹”方向：紫黑底、薄荷主操作色、淡紫历史色、珊瑚错误色、星点/轨道/扫描线几何。没有角色、场景、GIF、粒子贴图、外部图片、字体、QSS/QRC 或新增运行时依赖。动效只改变装饰绘制参数，状态文字和数据语义仍由既有 presentation/ViewModel 契约决定。

边界仍有效：只在当前 checkout `D:\Workplace\Agent_Workplace\SerialForge` 写入；未检测到 `.git`，没有创建或操作 worktree；不创建、修改或运行测试专用资产；不启动 GUI/EXE、服务、网络、UART/BLE/RTT 或真实硬件。

## 交付内容

- `theme.py`：重做紫黑星轨 QSS token、Header、Tab、分区标题、输入控件、按钮、表格、终端、错误条、状态徽章、Tooltip、滚动条和焦点态。
- `widgets.py`：增强 `StatusIndicator` 环形光晕/核心高光，以及 `SignalFieldWidget` 的星点、双轨道、扫描线和信号点；仍共用 `MotionController` 的单一时钟。
- `main_window.py`：标题改为“星轨串行实验室”；状态标签按 `SessionState` 动态换色；终端工具栏显示“实时/历史 · 最近 +N B · 窗口 N B”；补齐按钮 AccessibleName；关闭态早退、latest preview snapshot、文本边界和 PySide6 快捷键构造兼容修正。
- `viewmodels.py`：暴露有界 `preview_snapshot`；为 drain 批次汇总 `data_activity_changed`；`send_entry()` 拒绝关闭中、回放中和不可写状态。
- `command_batch_editor.py`：补齐步骤编辑、取消和保存按钮 AccessibleName。
- 其它 UI-1.5 的状态恢复、空态、TCP Server peer gate、Dataset 阅读位置、派生视图恢复与关闭 fence 保持不变。

## EXE 交付

官方入口：

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1 -Mode onefile
```

当前源码 canonical artifact：

`dist/release/0.1.0/core/onefile/app/SerialForge.exe`

根目录便利副本：

`SerialForge.exe`

两者均为 `47,626,447` bytes，SHA-256：

`60C498EFFE4B9B9B40E534D768424D6C4B974230AFAF627695BCBF54CF36A460`

`dist/release/0.1.0/core/onefile/PROVENANCE.json` 已由脚本内置 verification 通过，记录 Python `3.12.13`、PyInstaller `6.22.0`、PE `0.1.0.0`、`NotSigned`、`release_eligible=false`、`hardware_acceptance=not_run`。该产物是 unsigned engineering build，不等于正式发行或干净 Windows 启动通过。

Windows PowerShell 5.1 首次解析无 BOM UTF-8 的 `scripts/package.ps1` 失败，没有开始构建；改用当前环境的 `pwsh 7.6.4` 后成功完成两次 onefile 构建，最终根目录副本来自最后一次成功构建。

## 评审与简化

- 产品/UX 只读评审建议采用原创“夜航信号观测站”几何主题、限制渐变噪声、保持终端主路径；已整合为星轨几何和调试优先层级。
- 架构/动效只读评审确认 MotionController 是唯一共享时钟；本轮未新增控件级 QTimer、QPropertyAnimation 或业务状态到装饰控件的反向依赖。
- UI/API 只读评审发现快捷键 `QShortcut(..., activated=...)` 兼容风险以及主题 token 导出遗漏；已改为位置参数并补齐 `__all__`。
- 两份交付角色返回了非当前 checkout 的仓库上下文，未作为 SerialForge 证据采纳；父代理直接复核当前路径、manifest、PE 版本和 canonical/root hash。
- 独立简化结论：保留单一共享时钟；不新增素材目录、动画 timer、overlay 或业务层依赖；状态文字继续是权威表达，装饰动画可以停止并静态回退。
