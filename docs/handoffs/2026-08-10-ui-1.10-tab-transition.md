# UI-1.10 工作区切换动效交接

日期：2026-08-10

## 目标

让“链路 / 连接、协议 / 遥测、命令管理”工作区切换有轻量二次元工具站过渡感，同时不把动效状态扩散到业务层，也不重新引入白色系统表面。

## 本轮交付

- 在 `presentation/qt.py` 集中导出 `QEasingCurve`、`QPropertyAnimation`、`QGraphicsOpacityEffect`。
- `MainWindow` 在 `QTabWidget.currentChanged` 后对当前页面执行 180 ms、`OutCubic` opacity 淡入。
- 动画对象和 effect 使用 MainWindow 私有生命周期；重复切换会停止旧动画，恢复 opacity=1.0，再启动新动画。
- 低动效、暂停动效、隐藏、最小化、关闭均停止动画；已有非 opacity graphics effect 时跳过，不覆盖其他组件效果。
- `getattr` 防护保留了窗口构造期间系统低动效环境变量触发 toggle 的安全路径。

## 架构边界

- 变化只在 presentation 层：不修改 ViewModel、domain、application、transport、recorder、OTA 或 debug contract。
- 不新增 timer；动画沿用 Qt property animation，装饰性动效仍服从既有 MotionController/用户动效开关边界。
- 主题仍由 `theme.py` 提供深色 palette；动画不会写入业务状态或替换既有 QSS。
