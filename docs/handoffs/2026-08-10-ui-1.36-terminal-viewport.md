# UI-1.36 真实数据终端观测标尺

日期：2026-08-10  
范围：在保持真实 `QPlainTextEdit` 数据、选择、滚动和无障碍契约的前提下，为数据态终端增加轻量二次元观测标尺与共享扫描信号。

## 实现边界

- `src/serialforge/presentation/terminal_surface.py` 新增 `TerminalViewport`。
- `paintEvent()` 先调用原生 `QPlainTextEdit.paintEvent()`，再在现有 viewport 的上下 padding 内绘制低对比度上下标尺、四角 bracket
  和共享 frame 驱动的短扫描信号。
- `bootstrap.py` 仅将原有 `QPlainTextEdit#terminal` 替换为同契约子类；`lifecycle.py` 将 `_terminal` 纳入既有 motion surface
  fan-out，复用统一 `set_frame()/stop()` 生命周期。
- 不新增业务状态、RX/TX/吞吐/时间投影、QTimer、线程、控制器、主题 token、overlay 文本或传输依赖；窄 viewport 保留静态回退。
