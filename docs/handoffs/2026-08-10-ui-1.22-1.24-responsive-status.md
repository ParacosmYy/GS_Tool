# UI-1.22～UI-1.24 交付归档

日期：2026-08-10  
范围：协议/遥测响应式布局、批量命令状态表面、结果表白色回退、UART/TCP/BLE/RTT 响应式宽度

## 交付内容

- `protocol.py` 将协议首行改为可收缩的两行网格；长 preset/framing/checksum 不再传播页面硬宽度。
- Profile、Dataset、协议、Component、Curve、Replay 状态标签统一允许换行并保留完整辅助文本；Profile/Dataset 仍有非零可见宽度。
- `commandBatchStatus` 使用 `empty/ready/running/completed/stopped/failed` 状态投影；状态来源只使用选中 batch 与 `CommandBatchSnapshot`。
- 批量结果表、Component 表隐藏 Qt vertical header，保留业务步骤/序号列，消除系统 palette 白块。
- UART 端口、波特率、BLE device/characteristic/write mode、RTT channel、TCP Server peer 使用 bounded combo；TCP/RTT 长提示可换行。
- 主题基线与三套主题 override 均覆盖批量状态；静态门新增精确失败态 selector。

## 验证证据

- `.\scripts\check.ps1`：pass；104 个 Python 文件均不超过 1000 行；3 themes、22 semantic tokens、11 selectors。
- `QT_QPA_PLATFORM=offscreen`：980×680 下 UART、TCP Client、TCP Server、UDP、BLE GATT、RTT 页面均无 horizontal scrollbar。
- 最长协议选项、180 字符 Profile/Dataset、长 TCP peer/提示：页面无横向滚动；Profile/Dataset 实际宽度分别为 140/160px，完整 tooltip 保留。
- 三主题批量状态：`ready/running/completed/stopped/failed` 均产生不同主题表面，切换 batch 后旧 snapshot 不残留。
- 批量表 vertical header `visible=False`，viewport 扩展，左侧灰白回退像素为 0；TabBar 白线审计继续通过。
- 回放 `empty/playing/paused/eof/stopped/error` 三主题 state、按钮 gate、history source 复核通过。
