## 交付内容

- 新增 `src/serialforge/presentation/command_batch_surface.py`：
  `CommandBatchSurfaceProjection` 与 `CommandBatchSurfaceLabel`。它以最多 32 个 slot 绘制 pending/current/accepted/failed
  步骤轨道，保留原 `QLabel#commandBatchStatus` 的文字、tooltip、动态 `state` 和无障碍描述。
- 新增 `src/serialforge/presentation/replay_activity_surface.py`：
  `ReplayActivityProjection` 与 `ReplayActivityLabel`。它使用已有 replay state 与 `records_emitted` 绘制活动轨迹，不显示
  不存在的总记录数或百分比。
- `controllers/commands.py`、`controllers/replay.py` 只做 domain snapshot → presentation projection；
  `controllers/terminal.py`、`controllers/protocol.py` 只组装自绘 label；`controllers/lifecycle.py` 统一 fan-out frame 与
  stop。没有新增领域字段、业务进度源、ViewModel/transport 依赖或控件级 QTimer。
- 批量 running/replay playing 的短反馈沿用既有 `MotionController.request_activity()`；低动效、暂停、隐藏、最小化和关闭
  统一静态回退。自绘颜色统一来自 `theme_spec_for_widget()`，几何使用逻辑坐标和 `QRectF`。
