# UI-1.9 状态表面交接

日期：2026-08-10

## 目标

继续把 SerialForge 做成可读、可观察的二次元嵌入式调试工具站：状态必须有层级，动态颜色必须
来自既有 presentation 状态，不能把业务逻辑塞进主题层。

## 本轮交付

- `connectionContext` 使用深色上下文胶囊，连接方式/端点信息不再像普通散文标签。
- `sourceBadge` 增加 `source=live/history` 动态属性：实时使用薄荷青，历史使用紫蓝，文字仍明确写出来源。
- `pipelineSummary` 获得独立摘要带，突出 `Protocol → Component → Dataset → Curve` 链路。
- `pausedState` 和 `recordState` 增加 `idle/paused/active/stopping/error` 状态表面；不新增业务状态。
- `_set_dynamic_property()` 统一动态属性的变化检测与局部 polish，避免四处复制样式刷新代码。
- 主题没有白色背景规则；此前的 viewport、横向 scrollbar、corner 和 station band 暗色规则继续保留。

## 架构与交互边界

- 只改 `presentation/main_window.py` 与 `presentation/theme.py`；ViewModel、domain、application、transport、recorder 不变。
- 状态文本是事实，颜色只是辅助；暂停/记录/来源均保留 AccessibleDescription。
- 动态属性只在值变化时重新计算样式，不使用新的 timer，不制造高频 polish。
- 低动效/暂停动效边界没有变化；本轮没有给状态添加闪烁或脉冲动画。
