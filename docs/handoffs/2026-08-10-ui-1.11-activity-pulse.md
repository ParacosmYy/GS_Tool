# UI-1.11 接收活动动效交接

日期：2026-08-10

## 目标

让实时接收状态在工具栏中有短促、可辨识的动态反馈，同时保证“暂停显示”只影响终端可见性，不影响接收、记录和状态事实。

## 本轮交付

- `dataActivity` 增加 `state=active/idle` 样式状态。
- 只有 `SessionState.OPEN`、共享动效时钟处于 animated frame、且最近接收字节大于 0 时显示 active；活动窗口结束后回到 idle。
- active 使用深色薄荷渐变和边框，不引入白色表面，不依赖图片、GIF、字体或外部资源。
- 低动效、暂停、会话重置、隐藏、最小化、关闭会显式复位状态；动态属性只在状态边沿触发 polish。

## 架构边界

- 只修改 `presentation/main_window.py` 和 `presentation/theme.py`；不改变 ViewModel、domain、application、transport、recorder、OTA/debug contract。
- 复用既有 `MotionController`，不新增 `QTimer`；数据活动状态是 presentation 投影，不是新的业务状态。
- AccessibleDescription 继续说明最近接收字节、有界预览窗口和暂停显示语义，颜色不承担唯一信息表达。
