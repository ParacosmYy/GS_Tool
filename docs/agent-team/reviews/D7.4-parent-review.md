## Parent audit

The feature has a single application contract in `application/workspace_search.py`:

- `WorkspaceSearchPolicy` is immutable and validates configurable file, byte, directory-entry, depth, line, result, preview, issue, and excluded-directory bounds.
- `WorkspaceSearchQuery`, match, issue, and result DTOs are immutable and Qt-free.
- `WorkspaceSearchService` normalizes the explicit root, delegates to a provider, and rejects malformed provider counters, state combinations, relative/out-of-root match or issue paths, oversized previews, and limit violations.

`infrastructure/workspace_search_provider.py` is responsible only for local traversal and line scanning. It uses a strict per-directory entry sample, sorted traversal of the bounded sample, regular non-symlink/reparse filtering, bounded file/total byte admission, UTF-8/UTF-16 BOM text, CR/LF/CRLF line handling through `TextIOWrapper`, NUL binary detection, bounded issues, literal matching, and cooperative cancellation. It does not write, import, execute, call `DocumentStore`, or access a Qt widget.

`presentation/workspace_search_dialog.py` owns only controls and immutable result projection. `MainWindow` owns command registration, `TaskRunner` submission, the cancellation event, operation ID/generation, root-change invalidation, result activation containment recheck, asynchronous open, and one-based editor line navigation. The packaged probe is explicit and Qt-free; it is not a general external search API.

## Limits and unresolved risk

- The 2,000-file/64 MiB/4 MiB/4,096-entry/32-depth/256 KiB-line/10,000-result policy is a safety bound, not a measured support range, native-memory ceiling, or performance SLA.
- Search is literal and line-local only. Regex, whole-word, indexing, remote roots, archive contents, plugin search, and cross-file replacement remain out of scope.
- Evidence is from the current Windows x64 machine; Qt feature evidence is offscreen. Clean-machine, cross-machine, ACL/permission, disk-pressure, hard-power, and interactive feature-matrix evidence remain open.
- The provider rechecks symlink/reparse state and fails closed on Windows reparse metadata errors, but a complete handle-based no-follow/TOCTOU security boundary is not claimed. This search is read-only and not a sandbox.
- The optional cancellation callback now rejects falsey non-callable inputs;
  `None` uses an explicit no-cancellation callback and callable callbacks
  retain provider-owned cooperative semantics.
- No unit tests, mocks, fixtures, harnesses, or test-only assets were added or run, per the project operating policy.
