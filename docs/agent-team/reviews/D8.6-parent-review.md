# D8.6 parent review — release manifest completeness

- **Date:** 2026-08-09
- **Delivery:** D8 Enterprise release
- **Slice:** D8.6 manifest completeness and local provenance
- **Owner:** Architect (parent)
- **Disposition:** ACCEPTED WITH LIMITS; typed release decisions are complete
  for this source slice while legal/environment gates remain open

## Trigger

A read-only release audit found that D8-AC03 required an explicit file-
association state while the manifest emitted only signing, installer, update,
and support gates. The same audit found that the package script left
`source_revision` null despite the release policy requiring provenance. The
audit also confirmed the existing portable/manual/no-association intent in
ADR-0011; no installer or registry behavior was added.

## Fix audit

- `ReleaseManifest`, its atomic decoder, and the manifest writer now carry a
  typed `file_associations` gate.
- The package script computes a deterministic content/path tree digest over
  the build source inputs and passes it as `source_revision`.
- The release verifier checks that provenance and file-association decisions
  are explicit and includes the current file-association state in the dossier's
  open gates.
- The change does not weaken the no-go decision or infer legal clearance from
  the NOTICE inventory.

## Limits

- The tree digest is local provenance, not a Git commit or signed supply-chain
  attestation; the checkout has no Git metadata.
- NOTICE/legal completeness, signing, installer implementation, update channel,
  clean-machine, cross-machine, and runtime evidence remain open.
- No software launch, installer, registry mutation, or runtime verification was
  performed; no unit tests or test-only assets were added or run.
