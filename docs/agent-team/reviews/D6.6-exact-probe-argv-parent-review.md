# D6.6 exact probe-entry argument review

- **Delivery:** D6.6 process-isolated plugin host protocol
- **Date:** 2026-08-10
- **Owner:** Architect (parent)
- **Disposition:** ACCEPTED WITH LIMITS; the exact entry guard is source-verified,
  while fresh packaged/runtime evidence remains intentionally open

## Finding and decision

The host entrypoint previously accepted any argument sequence containing
`--probe`. That was wider than ADR-0018's documented entrypoint and allowed a
direct or malformed invocation to enter the host protocol path without the
`--plugin-host` mode marker.

The smallest compatible correction is in
`src/quillforge/plugins/host_process.py`: normalize the incoming arguments to a
tuple, then accept only `argv[0] + --plugin-host + --probe` in that order. The
single `_is_exact_probe_invocation` helper rejects unknown, duplicate, extra, or
reordered flags before any stdio read or protocol frame is emitted. The normal
source and frozen launchers already provide that exact shape.

## Architecture review

Terra/max reviewer `019fe7c0-8c26-7992-8504-1e5d517fa760` returned `REVISE`
before the edit: require both mode and probe flags, preserve `argv[0]`, and
reject undeclared/duplicate arguments. The parent Architect accepted that
bounded recommendation and made the one-file change in the shared checkout;
no other writer was active.

## Independent review and simplification

Fresh Luna/max reviewer `Sagan`, agent
`019fe7c8-8547-7f51-b562-c68f17265559`, returned `PASS` after the parent
clarified that `run_plugin_host` converts `sys.argv` to a tuple before calling
the helper. The review confirmed both formal entrypoints produce the required
three-element shape and that exact comparison rejects unknown, extra, duplicate,
and reordered arguments.

Earlier Luna reviewer `Locke`, agent `019fe7c6-b4d9-7423-946e-d394b7921e39`,
could not obtain a Git diff in this Git-less checkout and returned
`no-conclusion`; no child PASS is attributed to that window.

The simplification assessment is PASS: one normalization boundary plus one
pure predicate is clearer and lower-risk than scattered flag-presence checks,
with no change to the protocol codec, process containment, PID provenance, or
execution-disabled invariant.
