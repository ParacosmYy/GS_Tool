## Required invariants

1. No QScintilla widget or API crosses into `TaskRunner`.
2. Empty documents, trailing newlines, Unicode, CR/LF/CRLF text returned by the adapter, and long ASCII lines reconstruct exactly from capture chunks.
3. A stale `content_version` cancels the capture and preserves the previous valid snapshot.
4. The chunk store writes only to a same-directory temporary file until flush/fsync and atomic replace succeed.
5. Chunk writer failure leaves no final or temporary partial snapshot.
6. Worker JSON encoding does not call `"".join(chunks)`.
7. The default application path now bounds recovery handoff at 64 chunks/1 MiB
   plus one candidate chunk; larger-workload support, clean-machine behavior,
   permission/disk pressure, hard-power durability, cross-machine behavior,
   and a product native-memory ceiling remain explicitly unclaimed.
