## Finding and change

The previous D8.5 correction exposed a regression path: a later package could
change the artifact while `docs/RELEASE_HANDOFF.md` remained stale, and the
release verifier would not name that mismatch. The smallest repair adds
`human_handoff_identity_match` to `scripts/verify_release_handoff.ps1`.

The check requires the human handoff to contain the current root EXE SHA-256,
invariant-culture formatted byte count, and manifest `tree-sha256:` source
snapshot. It is included in the generated dossier's mechanical checks and
therefore fails closed without rewriting runtime evidence or changing the
existing `no-go` decision.

## Parent review and simplification assessment

report behavior. The check is a direct three-field string contract over an
already-required Markdown handoff; no parser dependency or broad release
abstraction was added. This is the smallest maintainable enforcement for the
document's existing identity contract.

No child review was required for this narrow documentation/release-tooling
change, and no independent PASS or certification claim is made. The separate
