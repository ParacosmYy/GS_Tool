## Implemented boundary

- host_protocol.py now accepts exactly one capability, probe.
- hello and probe-result frames reject execution_enabled=true as a protocol
  error; the false value is mandatory, not merely type-checked.
- PluginHostProbeResult rejects any true execution value at the application
  boundary.
- Existing infrastructure maps protocol violations to protocol-error with the
  safe disabled default; an untrusted true value cannot reach the UI.
- acceptance.json makes the capability allowlist and false-state invariant
  configurable thresholds, and scripts/check.ps1 validates them.
- ADR-0024 records the decision and future protocol-version boundary.

The boundary remains diagnostic-only. The global application execution gate is
still disabled and no external code can load or execute.
