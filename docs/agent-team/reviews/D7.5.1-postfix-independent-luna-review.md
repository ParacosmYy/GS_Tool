# D7.5.1 post-fix independent Luna review

- **Date:** 2026-08-09
- **Delivery:** D7.5.1 local session continuity
- **Reviewer:** Carver / `luna_max` (read-only independent review)
- **Scope:** Static data-safety and call-chain review after the invalid-manifest preservation fix
- **Disposition:** `PASS` for the current bounded contract; no `REVISE` finding

## Evidence reviewed

- `src/quillforge/infrastructure/session_store.py` — bounded read, typed
  absent/invalid mapping, and atomic save path.
- `src/quillforge/application/ports.py` — `SessionLoadResult` state contract.
- `src/quillforge/application/session.py` — valid-only normalization and safe
  default preservation.
- `src/quillforge/presentation/main_window.py` — startup baseline, session save,
  close guard, explicit repair, and latest-wins behavior.
- `docs/adr/0023-local-session-continuity.md` and
  `docs/adr/0026-session-invalid-state-preservation.md` — aligned product and
  data-safety contract.

## Review conclusions

| Requirement | Disposition | Evidence |
|---|---|---|
| Malformed input | PASS | `JsonSessionStore.load()` maps bounded decode/schema/field failures to `invalid` without writing. |
| Oversized input | PASS | The store reads at most `max_bytes + 1`, returns `invalid` when exceeded, and does not replace source bytes. |
| Absent input | PASS | Only `FileNotFoundError` maps to `absent`; invalid content does not collapse into first-run absence. |
| Startup no-overwrite | PASS | `MainWindow` seeds the safe baseline from invalid/absent state and unchanged startup skips the save. |
| Close no-overwrite | PASS | Close requests a save only through the existing boundary; unchanged invalid state is not rewritten and pending work blocks close. |
| Explicit repair | PASS | A later workspace/tab/caret change produces a new snapshot, which is atomically written through a same-directory temporary file. |
| Latest-wins | PASS | A newer snapshot replaces the pending snapshot while the single-flight write drains; `TaskRunner` retains the task through callback delivery. |

## Limits

The review does not claim dirty/untitled session text, encryption, multi-instance
locking, hard-power durability, cross-machine/cloud sync, or large-file support.
Those limits match ADR-0023/ADR-0026 and the D7.5.1 acceptance record.
