## Implementation audit

The delivered contract is split across the following seams:

- domain/models.py and domain/path_identity.py: immutable session DTOs,
  schema version, cursor validation, and filesystem-independent path identity.
- application/session.py: version check, safe defaults, duplicate removal,
  path/document/cursor bounds, and normalization.
- application/ports.py: SessionStore and EditorEngine cursor contracts.
- infrastructure/session_store.py: user-local JSON, bounded single-read load,
  same-directory temporary file, flush/fsync, atomic replace, and fail-closed
  malformed or oversized handling.
- presentation/editor_widget.py: adapter-level cursor capture and clamped
  cursor restore.
- presentation/main_window.py: Recovery-first startup barrier, workspace
  restore, serial document opening, missing/duplicate/deferred path handling,
  debounced latest-wins session writes, shared path identity, and close guard.
- app.py: composition-root wiring to LOCALAPPDATA session.json and startup
  restore.

The session file persists only schema_version, workspace_root, clean
path-backed document order, line/column caret metadata, and active_index. It
does not persist text, dirty or untitled payloads, undo state, selection,
scroll, layout, plugin state, cloud state, or multi-instance state.

## Review findings and fixes

The architecture review returned REVISE with three findings:

1. A recovery dialog dismissed by window close or Esc had no clicked button
   branch. Dismissal now has Later semantics; the same-path session entry is
   deferred and cannot replace the still-available recovery snapshot.
2. The D7.5 UI paths no longer call Path.resolve. A shared
   domain.path_identity.path_key compares already-normalized absolute paths;
   document save canonicalization stays behind DocumentService in TaskRunner.
3. Acceptance evidence and the D7.5.1 parent artifact were pending. Both are
   now recorded with source/offscreen smoke and package identity.

The simplification review returned REVISE. Its findings were integrated:

- removed unused session-load state;
- extracted the workspace-restore completion helper;
- removed a redundant JSONDecodeError exception entry;
- fixed the latest-wins race where reverting to an older snapshot while a
  newer write was in flight could otherwise be deduplicated incorrectly.

The after-source reviewer timed out and was closed without a verdict; no
after-source child PASS is claimed. The parent review therefore relies on the
source audit, the explicit simplification fixes, and the deterministic
offscreen production-path smokes below.

## Limits and open gates

- Only clean path-backed metadata is remembered; dirty and untitled content
  remains Recovery-owned.
- The profile is Windows-first and user-local; paths can become invalid after
  moves, permissions changes, profile changes, or machine changes.
- There is no claim for crash or hard-power durability, cross-machine
  migration, multi-instance locking, cloud sync, selection/scroll/layout
  continuity, plugin continuity, encryption, or large-file support.
- The package is portable one-file output only; Authenticode signing,
  installer, update channel, clean-machine verification, and broader release
  handoff gates remain open.
- The current Qt environment emits a missing-font-directory warning during
  offscreen smoke; it did not affect the asserted state transitions.
