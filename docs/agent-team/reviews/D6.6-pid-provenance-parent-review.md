# D6.6 parent review — plugin-host PID provenance

- **Date:** 2026-08-09
- **Delivery:** D6.6/D6.7 plugin-host diagnostic boundary
- **Owner:** Architect (parent)
- **Disposition:** ACCEPTED WITH LIMITS; PID-source ambiguity is removed, but
  the diagnostic host remains non-executable and runtime wrapper coverage is
  open

## Trigger and independent review

A read-only Luna review identified that `PluginHostProbeResult.host_pid` mixed
the parent-observed `process.pid` on pre-handshake failure paths with the
protocol-reported PID on successful paths. Terra then performed the required
high-risk cross-process review. Terra advised separating launcher and reported
host provenance, explicitly rejecting an unconditional PID-equality check, and
keeping PID values outside authorization.

The Terra review is recorded as a repair recommendation, not as an independent
completion PASS. The parent owns integration and verification.

## Parent audit and fix

- `PluginHostProbeResult.launcher_pid` now represents only the process adapter's
  observed PID.
- `PluginHostProbeResult.reported_host_pid` is `None` until a hello frame is
  decoded, then carries the hello PID through the result/error projection.
- Timeout, crash, output-limit, and pre-hello protocol failures retain only the
  launcher PID.
- Hello/result PID equality is still checked inside the protocol exchange, but
  launcher/report PID equality is intentionally not required for the documented
  wrapper/re-exec compatibility path.
- `PluginExecutionEvidence` and `PluginExecutionGate` remain unchanged and do
  not consume PID values; external execution remains disabled.

## Limits and evidence boundary

- This change does not authenticate a process, verify its image or signature,
  or prove Job Object membership from a JSON PID.
- Direct frozen-host and wrapper/re-exec runtime coverage is unrun because the
  current project instruction prohibits launching the software.
- No unit tests, mocks, fixtures, harnesses, or test-only assets were added or
  run.
- Independent after-source simplification review remains unavailable; no child
  PASS is claimed.
