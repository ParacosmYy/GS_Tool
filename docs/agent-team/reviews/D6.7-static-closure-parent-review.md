## Public platform-source applicability

The applicable first-party platform references are the Microsoft Learn Win32
contracts already recorded in ADR-0019 and ADR-0028: `CreateJobObjectW`,
`AssignProcessToJobObject`, `SetInformationJobObject`, the Job Object limit
structures, `CreateProcessW`, Tool Help thread enumeration, and
`ResumeThread`. They apply only to the Windows x64 containment adapter. They
are engineering/platform contracts, not certification or complete sandbox
evidence.
