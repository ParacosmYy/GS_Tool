## Parent audit

- `plugins.host_protocol` is a Qt-free pure-Python wire contract with protocol
  name/version, newline-terminated UTF-8 frames, 64 KiB frame cap,
  duplicate-key rejection, strict envelopes, bounded error text, and no
  plugin/module payload fields.
- `plugins.host_process` handles only `--plugin-host --probe`, writes hello,
  validates one probe request, writes a result with `execution_enabled=False`,
  and exits without importing Qt, catalog descriptors, or plugin modules.
- `SubprocessPluginHost` uses an exact argument list with `shell=False`, pipes
  stdio, uses `CREATE_NO_WINDOW` on Windows, reads stdout/stderr through
  bounded reader threads, applies a timeout and kill path, and maps start,
  timeout, non-zero exit, oversized output, malformed framing, PID mismatch,
  and unsupported messages to typed results. The self-reported host PID is
  checked to differ from the main process and to remain consistent across
  hello/result; it is not treated as a signature or OS identity proof because
  Windows launchers can re-parent/re-exec an interpreter.
- `MainWindow` exposes Plugin Host Diagnostics through `TaskRunner`, operation
  IDs, and close-event in-flight protection. The application port receives only
  `PluginHostProbeResult`; no widget or manager object crosses the process
  boundary.
- The composition root bundles the `--plugin-host` route. External catalog
  discovery, descriptor approval, and local enablement remain disconnected from
  execution; the host explicitly reports execution disabled.

## Superseding handle-conversion audit

The later parent audit found one concrete Windows ctypes defect that supersedes
the earlier statement that no source patch was justified: `_Win32JobApi` used
`int(handle)` for `wintypes.HANDLE` values in `create_job()` and
`open_process()`. A local type probe reproduced `ValueError` for that direct
conversion. The source now uses `int(handle.value)` at both boundaries.

The repair is recorded in
`docs/agent-team/reviews/D6.6-handle-conversion-parent-review.md` and does not
close D6.6: Luna and Terra were requested again but returned no independent
conclusion in their bounded windows, and fresh packaged host/containment
evidence remains prohibited or unavailable.
