# D7.5.1 Follow-up Parent Review

- Date: 2026-08-09
- Delivery: D7.5.1 local session continuity follow-up
- Owner: Architect
- Disposition: ACCEPTED WITH LIMITS; the invalid-state overwrite finding was
  fixed and the post-fix independent review returned PASS.

## Trigger

The independent Luna review of the original D7.5.1 implementation returned
`REVISE` with a high-severity data-safety finding: the session store collapsed
absent and malformed/oversized/unsupported input to the same `None` result.
Startup and close could then save the empty safe snapshot and replace the
original bytes before diagnosis or recovery.

## Fix

- `application.ports.SessionLoadResult` now distinguishes `absent`, `valid`,
  and `invalid` state.
- `JsonSessionStore` returns `invalid` for bounded read/decode/schema/size
  failures and never writes during load.
- `SessionService` normalizes only valid input and preserves the load state.
- `MainWindow` seeds the last-saved baseline from the load result, so an
  invalid manifest is not rewritten during unchanged startup or close; a
  later explicit session change can atomically repair it.

## Evidence

- Source smoke PASS: valid/absent/invalid load-state contract, corrupt and
  oversized byte preservation, and explicit repair.
- Real Qt/offscreen MainWindow smoke PASS: an invalid manifest remains byte-for-
  byte unchanged through recovery-free startup and close.
- Real Qt/offscreen MainWindow smoke PASS: a valid path-backed session restores
  serially and projects the saved caret.
- `scripts/check.ps1` PASS; the root/dist package is 38,169,860 bytes with
  SHA-256 `47E6EAAB0B24B1E784D678699B62430DFB82D68C50531911ABFAB0A3AA57227E`;
  startup, packaged capture, and handoff evidence are refreshed in the current
  release records.

## Review status and limits

The pre-fix independent review was `REVISE`. The post-fix independent Luna
review returned `PASS` and is recorded in
`docs/agent-team/reviews/D7.5.1-postfix-independent-luna-review.md`. D7.5.1 is
accepted with limits. Multi-instance locking, hard-power durability,
cross-machine behavior, encryption, large recovery inventories, and
dirty/untitled session payloads remain outside the slice.
