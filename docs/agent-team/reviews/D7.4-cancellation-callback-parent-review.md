# D7.4 cancellation callback contract parent review

- **Date:** 2026-08-09
- **Delivery:** D7.4 bounded asynchronous workspace search
- **Owner:** Architect (parent)
- **Disposition:** PROCEED WITH LIMITS; the cancellation-input contract is
  repaired and independently reviewed, while runtime/search gates remain open

## Finding and fix

`WorkspaceSearchService.search()` previously selected its default cancellation
callback with `cancel_requested or ...`. A falsey non-callable value such as
`0` could therefore bypass the callable contract and be passed into the
provider. The service now distinguishes `None`, rejects every non-callable
value, and preserves callable callbacks. The default is an explicit
`_never_cancelled()` function.
