## Findings

The prior malformed-evidence defect is fixed. `PluginExecutionGate.evaluate()`
now short-circuits every non-well-formed `PluginExecutionEvidence` instance to
the immutable `invalid-evidence` decision before any untrusted field can enter
policy comparisons. `_is_known_text()` requires an exact `str` and uses a
tuple allowlist, so an unhashable field such as a list cannot raise from set
membership validation.

The `executor-unavailable` deny reason is now aligned across
`src/quillforge/application/plugin_execution.py`, ADR-0020, the D6-AC08
acceptance record, and the D6.8 delivery register. The composition still uses
the disabled global policy; catalog projection remains metadata-only with no
external loader or callback path.

## Limits

This was a read-only source/document audit. No files were edited, QuillForge
was not launched, no Qt application was instantiated, and no tests, mocks,
fixtures, harnesses, or test-only assets were created or run. The result does
not establish executable-plugin authorization, a complete sandbox, runtime
behavior, or a security/certification claim.
